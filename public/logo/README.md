# Logo

`logo.jpg` is het logo van De Straat Lacht (bijgesneden uit `public/assets/`), wit op zwart.
De website laat de zwarte achtergrond wegvallen via CSS (`mix-blend-mode: screen`).

Nieuw logo? Vervang `logo.jpg` door een nieuw bestand met dezelfde naam. Een andere naam of
extensie (bijv. `logo.png` of `logo.svg`)? Pas dan `logoSrc` aan in `src/config.js` én de
`src` van de `<img>` in `index.html`.

Ontbreekt het bestand, dan toont de website automatisch een typografische placeholder.
